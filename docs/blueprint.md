# **App Name**: SenhaFácil

## Core Features:

- Ticket Generation: Generate sequential and unique ticket numbers for each new user.
- Ticket Display: Display the current ticket number being served and a list of the next few tickets.
- Ticket Management: Allow staff to advance to the next ticket number with a button click.

## Style Guidelines:

- Primary color: Blue (#3498db) for a professional and trustworthy feel.
- Secondary color: Light gray (#ecf0f1) for backgrounds and subtle elements.
- Accent: Green (#2ecc71) to highlight the current ticket and call-to-action buttons.
- Clean and readable fonts like Open Sans for ticket numbers and instructions.
- Clear separation of sections for ticket generation, display, and management.
- Use simple icons for visual cues, such as a 'next' icon for advancing tickets.
